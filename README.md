# SportSpace Manager

Курсовой проект на тему: **разработка системы управления спортивными секциями и расписанием тренировок**.

Текущий этап проекта закрывает фронтенд-основу под критерии из `docx`:

- роли пользователей: администратор, тренер, спортсмен, родитель;
- демонстрация регистрации и авторизации по ролям;
- личный кабинет с редактированием данных пользователя;
- просмотр спортивных секций и запись в секции;
- формирование и изменение расписания тренировок;
- контроль занятости залов и тренеров при переносе тренировки;
- ведение списка участников и журнал посещаемости;
- просмотр достижений спортсменов;
- административная панель с общей статистикой.

## Стек

- React 19
- Vite 8
- React Router DOM 7
- ESLint 9

## Запуск проекта

1. Установить зависимости:

```bash
npm install
```

2. Запустить dev-сервер:

```bash
npm run dev
```

3. Собрать production-версию:

```bash
npm run build
```

4. Проверить линтер:

```bash
npm run lint
```

## Демо-аккаунты

Все роли используют один демо-пароль: `sport2026`

- Администратор: `admin@sport.local`
- Тренер: `coach@sport.local`
- Спортсмен: `athlete@sport.local`
- Родитель: `parent@sport.local`

## Структура проекта

```text
src/
  components/      UI-компоненты и layout
  context/         общее состояние приложения
  data/            демо-данные по секциям, расписанию и участникам
  pages/           страницы маршрутов
  routes/          конфигурация React Router
  utils/           форматирование и вспомогательные функции
```
